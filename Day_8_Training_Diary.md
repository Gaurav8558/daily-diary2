# Day 8 -- Introduction to Node.js

**Topic Covered:** Introduction to Node.js, Features, Architecture,
Installation and Runtime Environment.

## Daily Training Diary

Today, I learned about **Node.js**, an open-source, cross-platform
JavaScript runtime environment that allows developers to execute
JavaScript code outside a web browser. I understood that Node.js is
commonly used for backend development because it provides tools for
building servers, APIs and other network-based applications.

I studied the main features of Node.js, including its asynchronous and
event-driven architecture, non-blocking I/O, cross-platform support and
large package ecosystem through NPM. I learned that Node.js uses the V8
JavaScript engine to execute JavaScript and is designed to handle many
I/O operations efficiently.

I was introduced to the basic architecture of Node.js, including the
call stack, event loop, callback queues and underlying asynchronous I/O
mechanisms. I understood how the event-driven model helps Node.js handle
operations such as network requests and database communication.

I also learned how to install Node.js and verify the installation using
terminal commands such as `node -v` and `npm -v`. I explored how to
execute a JavaScript file using the Node.js runtime and how to use the
Node.js REPL (Read-Eval-Print Loop) to run JavaScript statements
interactively.

## Practical Learning

I performed the initial setup of the Node.js development environment. I
verified the installed Node.js and NPM versions, created a basic project
directory and executed a simple JavaScript program using the Node.js
command.

I also discussed how Node.js would be used in the Banking Ledger
Management System. It would act as the backend runtime responsible for
receiving client requests, executing banking business logic,
communicating with MongoDB and returning API responses.

## Learning Outcomes

-   Understood what Node.js is and why it is used for backend
    development.
-   Learned the major features of Node.js, including non-blocking I/O
    and event-driven execution.
-   Gained a basic understanding of Node.js architecture and its use of
    the V8 engine.
-   Learned how to install and verify Node.js and NPM.
-   Practiced executing JavaScript files using Node.js.
-   Understood the role of Node.js in the Banking Ledger Management
    System.
