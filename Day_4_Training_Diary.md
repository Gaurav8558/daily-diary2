# Day 4 -- JavaScript Functions, Arrays and Objects

**Topic Covered:** Functions, Arrow Functions, Arrays, Objects and
Common Array Methods.

## Daily Training Diary

Today, I learned about JavaScript functions and how they help organize
code into reusable blocks. I understood that functions make programs
easier to maintain, reduce code repetition and allow specific tasks to
be performed whenever required.

I studied how to declare and call functions using function declarations
and function expressions. I also learned about parameters and arguments,
return statements, and the scope of variables inside functions.

I was introduced to **arrow functions**, which provide a shorter syntax
for writing functions in JavaScript. I practiced using arrow functions
for simple calculations and data-processing operations.

I also studied **arrays**, which are used to store multiple values in a
single variable. I learned how to access, add, remove and modify array
elements using their indexes and common methods such as `push()`,
`pop()`, `shift()`, `unshift()` and `includes()`.

Furthermore, I learned about commonly used array iteration and
transformation methods:

-   **forEach():** Executes a function for each array element.
-   **map():** Creates a new array by transforming existing elements.
-   **filter():** Creates a new array containing elements that satisfy a
    condition.
-   **find():** Returns the first element that satisfies a condition.
-   **reduce():** Combines array elements into a single value.

I also studied **JavaScript objects**, which store information in
key-value pairs. I learned how to create objects, access and update
their properties, and use nested objects to represent structured
information.

## Practical Learning

I practiced writing reusable functions, manipulating arrays and
accessing object properties through small JavaScript programs.

I related these concepts to the Banking Ledger Management System. For
example, an array can represent a collection of transactions, while
objects can represent individual customers, bank accounts and
transaction records.

Array methods such as `filter()` can be used to select transactions of a
particular type, while `reduce()` can help calculate totals from a
collection of transaction records.

## Learning Outcomes

-   Understood the purpose and structure of JavaScript functions.
-   Learned function declarations, expressions and arrow functions.
-   Practiced creating and manipulating arrays.
-   Understood commonly used array methods such as `map()`, `filter()`
    and `reduce()`.
-   Learned how to create, access and modify JavaScript objects.
-   Understood how arrays and objects can represent banking data.
