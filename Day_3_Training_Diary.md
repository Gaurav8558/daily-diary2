# Day 3 -- JavaScript Fundamentals

**Topic Covered:** Variables, Data Types, Operators, Conditional
Statements and Loops.

## Daily Training Diary

Today, I learned the fundamentals of JavaScript, which is an important
programming language used in backend development with Node.js. I
understood how JavaScript allows developers to write program logic,
perform calculations, process data and implement application
functionality.

I studied the concept of **variables** and learned how to declare and
store data using `var`, `let` and `const`. I understood the differences
between these keywords, particularly their scope and reassignment
behavior.

I also learned about different JavaScript data types:

1.  **String:** Used to store textual information, such as customer
    names and email addresses.
2.  **Number:** Used to store numerical values, such as account balances
    and transaction amounts.
3.  **Boolean:** Represents logical values, either true or false.
4.  **Undefined:** Represents a variable that has been declared but not
    assigned a value.
5.  **Null:** Represents the intentional absence of a value.
6.  **Object:** Used to store data in key-value pairs.
7.  **BigInt and Symbol:** Additional primitive data types used for
    large integers and unique identifiers.

Furthermore, I studied different types of operators, including
arithmetic, assignment, comparison and logical operators. I learned how
conditional statements such as `if`, `else if` and `switch` are used to
execute code based on specific conditions.

I also practiced loops, including `for`, `while` and `do-while`, which
help execute a block of code repeatedly.

## Practical Learning

I practiced JavaScript programs involving variable declaration,
mathematical calculations, comparisons and conditional statements.

I related these concepts to the Banking Ledger Management System. For
example, conditional statements can be used to check whether an account
has sufficient balance before processing a withdrawal. Arithmetic
operators can calculate transaction amounts and account balances, while
Boolean values can represent account status conditions.

## Learning Outcomes

-   Understood JavaScript variables and their declaration methods.
-   Learned primitive and non-primitive data types.
-   Gained knowledge of arithmetic, logical and comparison operators.
-   Learned to implement conditional statements and loops.
-   Understood how JavaScript fundamentals are applied in banking
    application logic.
