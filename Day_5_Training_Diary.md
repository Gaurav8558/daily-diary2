# Day 5 -- Modern JavaScript (ES6+) Features and Modules

**Topic Covered:** ES6+ Features, Template Literals, Destructuring,
Spread Operator, Rest Parameters and JavaScript Modules.

## Daily Training Diary

Today, I learned about modern JavaScript features introduced in
ECMAScript 6 (ES6) and later versions. I understood how these features
make JavaScript code more readable, concise and easier to maintain,
particularly when developing backend applications using Node.js.

I revised the use of `let` and `const` for declaring variables and
studied **template literals**, which allow strings to be created using
backticks and expressions to be inserted with `${}`. This makes it
easier to construct dynamic messages and text.

I also learned about **destructuring**, which provides a convenient way
to extract values from arrays and properties from objects into separate
variables. I studied the **spread operator (`...`)**, which can be used
to expand elements of an array or properties of an object. I also
learned about **rest parameters**, which allow a function to accept
multiple arguments as an array.

Another important concept covered today was JavaScript modules. I
learned how code can be divided into separate files and reused through
imports and exports. I studied the CommonJS module system, including
`require()` and `module.exports`, which is commonly used in Node.js
applications. I also learned about ES Modules and their `import` and
`export` syntax.

## Practical Learning

I practiced using template literals, destructuring, spread operators and
rest parameters through small JavaScript programs. I also created
separate JavaScript files and learned how to export functions or values
from one file and import them into another.

I related these concepts to the Banking Ledger Management System. For
example, destructuring can be used to extract customer details from an
object, while template literals can help create transaction messages.
Modules can separate account-related, authentication-related and
transaction-related functionality into different files, making the
backend project easier to organize and maintain.

## Learning Outcomes

-   Understood modern JavaScript ES6+ features.
-   Learned to create dynamic strings using template literals.
-   Practiced array and object destructuring.
-   Understood the spread operator and rest parameters.
-   Learned the basics of CommonJS and ES Modules.
-   Understood how modular code organization helps structure a Node.js
    backend application.
