# Day 1 -- Introduction to Web Development and Client-Server Architecture

**Topic Covered:** Introduction to Web Development, Frontend and Backend
Architecture, and Client-Server Communication.

## Daily Training Diary

Today, I learned about the fundamentals of web development and the
different components involved in building a web application. I
understood how web applications work and how the frontend and backend
communicate with each other to provide functionality to users.

I learned about the two major parts of web development:

1.  **Frontend Development:** It is the client-side part of an
    application that users interact with. It includes the user
    interface, layouts, buttons, forms and other visual elements.
    Technologies such as HTML, CSS and JavaScript are commonly used for
    frontend development.

2.  **Backend Development:** It is the server-side part of an
    application responsible for handling business logic, processing
    requests, managing databases, authentication and data operations.
    Technologies such as Node.js, Express.js and MongoDB are used in
    backend development.

I also studied the **Client-Server Architecture**, in which a client
sends requests to a server, the server processes those requests and
returns an appropriate response. I understood the role of servers,
databases and APIs in this communication process.

## Practical Learning

As an introduction to the training project, I studied how these concepts
would be applied in a Banking Ledger Management System. I understood
that the frontend would send requests to the backend for operations such
as user registration, account creation, checking account balances and
transferring funds.

The backend would process these requests, interact with the MongoDB
database and return the required responses.

## Learning Outcomes

-   Understood the fundamentals of web development.
-   Learned the difference between frontend and backend development.
-   Understood client-server architecture and communication.
-   Learned the basic responsibilities of a backend developer.
-   Gained an overview of how a banking ledger system operates from a
    backend perspective.
